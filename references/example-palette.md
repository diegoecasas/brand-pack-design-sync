# Example palette — Mascotearte ("Estudio Alegre")

This is a full worked palette from a real brand. Use it as a **template**, not as content to copy — every brand should get its own palette after Step 1 research.

## The palette

| Name | Hex | Role |
|---|---|---|
| Lienzo Crudo | `#F4EBDD` | Base background. Warm cream, canvas before gesso. Never use `#FFFFFF` puro. |
| Tinta Nocturna | `#141215` | Text and outlines. A warm ink black, not pure black. |
| Cadmio Vivo | `#F26A1F` | Main accent. Cadmium orange (oil-paint pigment). Energy and warmth. |
| Cobalto Estudio | `#1E4FCC` | Secondary accent. Deep cobalt blue. Contrast and "premium". |
| Ocre Antiguo | `#C48A3B` | Warm detail. Gold frame, amber highlights. |
| Verde Ftalo | `#2A6E5A` | Tertiary accent. Muted phthalo green. Nature, calm, breathing space. |

## Usage rules
- **Backgrounds**: Lienzo Crudo (light) or Tinta Nocturna (dark). Never pure `#FFFFFF`.
- **Titles/UI**: Tinta Nocturna on Lienzo Crudo, or Lienzo Crudo on Tinta Nocturna.
- **CTAs and energetic accents**: Cadmio Vivo. It's the "joyful" color — use it hungry.
- **Premium details**: Cobalto + Ocre together read "art gallery", not "e-commerce".
- **Verde Ftalo**: for breathing. Secondary section backgrounds, badges, illustration.
- **Forbidden**: baby pink, baby blue, kraft/manila, unicorn gradients, any color outside these 6.

## Why this palette dodges the category cliché

The pet-portrait category converges on: pure white backgrounds + pastel pink/blue accents + isabelline serif type + "royal renaissance" gimmick. This palette does the opposite:
- **Warm cream instead of pure white** — reads "atelier", not "e-commerce photo studio"
- **Painter's pigments (cadmium/cobalt/ochre/phthalo)** instead of soft pastels — reads "real materials", not "kids brand"
- **Warm ink black instead of pure black** — physical, hand-mixed, alive
- **Zero pastels** — the vibe is "alegre premium", not "cute nursery"

## Palette-selection heuristic

Whatever the category, run this filter:
1. What color/font clichés does the category converge on? (screenshot 3-5 competitors)
2. Pick a base tone the category is NOT using (warm-cream if everyone is on pure white; deep charcoal if everyone is on soft gray; muted olive if everyone is on beige)
3. Pick 1 saturated accent that reads "the thing they sell" (cadmium orange = paint; deep crimson = wine; forest green = plants; sunset amber = whiskey)
4. Pick 1-2 supporting accents that let you build hierarchy without needing to add another hue later
5. Confirm your palette works in dark mode — if you can't invert base + text, you need a 6th color

The point is not to be different for the sake of it. The point is to look like a brand that came from a person, not a template.
